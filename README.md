# Sift

> Your feed is optimized for the platform. Sift is optimized for you.

Sift auto-curates a feed while you scroll. You share a browser tab or window with Sift using
the browser's standard screen-share prompt; Sift watches what appears, understands each post or
reel with Meta's Muse Spark, and builds a live curated stream: valuable items are highlighted
with a one-line reason, low-value ones collapse. It learns what you care about from how you
behave (dwell, save, hide), with no setup.

**Built during the Meta Global AI Developer Hackathon, Oct 27 to Nov 4, 2026. All code, content
and docs in this repository were written during that window** (see [CHANGELOG.md](CHANGELOG.md)).

Setup instructions and architecture are filled in as milestones land.
